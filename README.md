# gamified-security
Гейміфіковане середовище для навчання питанням інформаційної та кібербезпеки
__Used AI__

## Курси
- Безпечна розробка, Кібергігієна, Криптологія
- Захист критичної інфраструктури – КП «Теплоград» (вигадане): VLAN, ACL, МЕ, VPN, OSPF, Modbus, фінальний інцидент за мотивами атак 2015, 2016 і 2024 рр.

## Розробка
- `npm run dev` – локальний сервер
- `npm run build` – збірка
- `npm test` – тести (Node 22.6+ з підтримкою TypeScript)
