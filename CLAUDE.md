# Проєкт
Веб-прототип гейміфікованої платформи навчання безпеці (магістерська). Інтерфейс — українською.

## Обсяг прототипу
- Головна: картки курсів (secure-dev, cyber-hygiene, cryptology активні; cisco — «скоро»)
- Сторінка курсу: список завдань, статус, XP
- Екран завдання: умова, робоча зона за типом, кнопки «Перевірити» і «Підказка», розбір після перевірки
- XP, рівень і прогрес у localStorage

## Правила
- Завдання — це дані (JSON у /content); рушій не знає про конкретні теми
- Типи: multi-choice, find-in-code, text-answer; новий тип = новий компонент + функція перевірки
- Без бекенду, реєстрації та сторонніх сервісів
- Стек: React + TypeScript + Vite

## Не робимо зараз
Бекенд, логування експерименту, адмінка, бейджі, рейтинги
